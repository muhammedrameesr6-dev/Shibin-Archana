# Shibin & Archana — Wedding Invitation Website

A wedding invitation website cloned and customized from [vinay-athira-wedding.vercel.app](https://vinay-athira-wedding.vercel.app/).

## Features
- **Interactive Cover Overlay**: Card reveal with "OPEN INVITATION" button.
- **Background Music Player**: Plays *Neelashalabham* (instrumental/song) with smooth fade-in/fade-out audio controls and floating music button.
- **Dynamic Live Countdown**: Real-time countdown timer ticking down to 10th January 2027, 8:00 AM IST (Guruvayoor Thalikettu).
- **Parivar & Family Details**: Elegant cards with groom and bride family details, addresses, and one-tap call buttons.
- **Ceremony & Reception Details**:
  - **Thalikettu**: Guruvayoor Temple (8:00 AM – 8:30 AM) with direct Google Maps link.
  - **Wedding Reception**: FLG Auditorium, Changaramkulam with Google Maps link and scannable location QR code.
- **Pre-Wedding Moments Gallery**: Photo canvas with smooth zoom hover transitions.
- **Fully Responsive**: Dedicated mobile & desktop high-resolution traditional Kerala artwork backgrounds with floral dividers.
- **GSAP ScrollTrigger**: Smooth entrance reveals and typography styling.

## How to View Locally
Simply double-click `index.html` or open it in your browser:
```bash
open index.html
```

Or run a local HTTP server:
```bash
npx serve .
# or
python3 -m http.server 8080
```

## How to Deploy (e.g. Vercel)
1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "Initial commit for Shibin & Archana wedding invitation website"
   git branch -M main
   git remote add origin <your-github-repo-url>
   git push -u origin main
   ```
2. Import the repository in [Vercel](https://vercel.com) — zero configuration required!
